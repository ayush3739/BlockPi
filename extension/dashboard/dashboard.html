3 Fast Ways to Save & Bookmark Links

Never lose an insightful article, reel, repository, or paper again without interrupting your flow.

ads_click
Method 1 • Background Save

Right-Click Context Menu

Right-click any link on a page (Instagram Reels, YouTube Shorts, GitHub repos, articles) and choose:

bookmark 📌 Save link to BlockPi Vault

Pro Tip: Highlight text on any page and right-click → Save selected URL to attach the quote as your note automatically!

keyboard
Method 2 • Instant Hotkey

Global Keyboard Shortcut

Whenever you are browsing a valuable webpage or technical documentation, simply press:

Alt + S

Saves the active tab in <500ms and fires a desktop notification confirming your safe capture.

bookmark_add
Method 3 • Toolbar Clipper

1-Click Popup Header

Click the BlockPi extension icon in your browser toolbar, then tap the top-right save icon:

bookmark_add Save Current Tab

Flashes an animated green checkmark and syncs directly into your Vault table.
