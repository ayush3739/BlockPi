YouTube PWA Setup

Because of browser security, Chrome cannot directly open external apps. You need to install a small "Native Messaging Host" on your computer once.

  1. Open your Chrome extensions page (chrome://extensions).
  2. Find BlockPi and copy its ID.
  3. Open a Command Prompt or Terminal.
  4. Run the installation script located in the extension folder: 
    python "native/install.py"
  5. Paste your Extension ID when prompted.

Note: You must have Python installed on your PC.
