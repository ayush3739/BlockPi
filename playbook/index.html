01

Why Traditional Bookmarks Fail (The Bookmark Graveyard)

Everyone saves links. Almost nobody ever reads them. Here is why conventional bookmarking breaks down:

psychology_alt

The Collector's Fallacy

Saving a link produces a dopamine hit that feels like you've learned something. But saving is not learning. Without a capture context (why did you save it?), the link becomes digital clutter that you ignore.

folder_off

Rigid Folder Paralysis

Folders force every resource into a single home. If you find an article titled "FastAPI & PostgreSQL on Docker", do you file it under /Backend, /Database, or /DevOps? Tags solve this by allowing multiple overlapping dimensions.

tab_close

Capture Friction & Lost Focus

If saving an Instagram Reel, YouTube video, or blog requires opening a new tab, copying the URL, opening a bookmarks bar, and picking a folder, you get pulled out of your flow state and lose focus.

03

The 3-Dimensional Tagging Taxonomy

Never tag with random keywords. Use this three-dimensional model to make any resource discoverable in seconds.

DIMENSION A

Action / Status

What action does this resource require from you?

#to-read Long articles or essays to read with focus
#to-try Code libraries, CLI tools, or repos to run
#reference Cheat sheets, API specs, docs to keep forever
#swipe-file Inspiring UI designs, copywriting, landing pages
#archive Consumed items kept for historical search
DIMENSION B

Topic / Domain

What subject or technical domain does it cover?

#ai LLMs, Prompting, Model releases
#rag Vector databases, Embeddings, Chunking
#backend FastAPI, Node.js, Go, Microservices
#frontend React, CSS, Animations, UI architecture
#system-design Scalability, Caching, High availability
#dsa Data structures, Algorithms, LeetCode
DIMENSION C

Format / Media

What medium is this resource presented in?

#reel Instagram Reels, YouTube Shorts (quick tips)
#video Full YouTube tutorials, conference talks, demos
#repo GitHub repository or open-source codebase
#article Technical blog posts, substack, Medium
#paper ArXiv research papers, technical whitepapers
#tool SaaS product, utility webapp, extension
THE WINNING COMBO
#to-read + #rag + #paper ➔ "An ArXiv RAG paper I need to read this weekend"
04

Proven Frameworks: P.A.R.A. & Progressive Summarization

World-class productivity methodologies tailored specifically for your BlockPi Resource Vault.

P.A.R.A. Applied to Digital Links

Organization

Invented by Tiago Forte (Building a Second Brain), P.A.R.A. prioritizes resources based on their actionability, not just abstract subject matter.

P Projects
Resources tied to active projects with a deadline. (e.g. #proj-auth, #proj-portfolio). Highest review priority.
A Areas
Ongoing responsibilities without an end-date. (e.g. #area-devops, #area-health).
R Resources
Topics of ongoing curiosity or reference. (e.g. #res-postgres, #res-system-design).
A Archives
Completed project resources kept for cold search.

Progressive Summarization for Links

Retention

Never save just a bare link. Enrich it in layers over time so that retrieval is effortless:

Layer 1
The Raw Link: Saved via right-click or Alt+S.
Layer 2
The Key Quote: Highlighted snippet saved directly via BlockPi right-click selection.
Layer 3
The 1-Sentence Takeaway: Written in your own words in the notes box: "PostgreSQL HNSW index scales to 1M vectors with 98% recall at 3ms query latency."
05

BlockPi Vault Clipper: Pro-Tips & Shortcuts

Use the built-in clipper features to capture links with zero tab clutter.

link

Right-Click Any Link Without Opening It

Found an Instagram Reel, YouTube Short, or HackerNews link? You don't need to open 20 tabs. Right-click the link and click 📌 Save link to BlockPi Vault. It saves instantly in the background!

format_quote

Highlight Text to Capture Notes Automatically

Highlight an important quote, takeaway, or code snippet on an article, right-click, and select 📌 Save selected URL to BlockPi Vault. BlockPi attaches that highlighted text as your metadata note!

keyboard

Instant Shortcut: Alt + S

When you're on an interesting page, press Alt + S. A desktop notification confirms the active tab is safely tucked away in your Vault.

bookmark_add

1-Click Popup Save

Click the BlockPi extension icon in your Chrome toolbar and hit the bookmark_add icon in the header. It flashes a green checkmark to confirm the save.

06

The 5-Minute Weekly Triage Ritual

A simple Friday afternoon habit to achieve "Bookmark Inbox Zero" and prevent hoarding.

1

Open Your Resource Vault

Click the Bookmarks icon in BlockPi popup or head to dashboard.html#vault.

2

Filter by #to-read or This Week

Use the tag filter dropdown to view only items you tagged with #to-read or #to-try.

3

Apply the Rule of 3 (Act, Schedule, or Delete)

Quick (<3 min): Read it now → change tag to #reference.
Deep: Export to your Obsidian / Notion project.
Irrelevant: Click the trash button. Ruthless pruning keeps your vault high-signal!

The Obsidian & Notion Second-Brain Bridge

How to export your curated vault into your local Markdown knowledge base.

Export as Markdown (.MD)

Obsidian Ready

Click Export .MD in the Vault toolbar. BlockPi generates a standard GitHub-flavored Markdown table with clickable links, tags, notes, and dates:

description vault-export.md 
# BlockPi Resource Vault Export
Generated on: 2026-09-25

| Title | URL | Tags | Notes & Metadata | Saved Date |
| :--- | :--- | :--- | :--- | :--- |
| **FastAPI Best Practices** | [Link](https://fastapi.tiangolo.com) | `#backend` `#fastapi` | Use async db sessions | 2026-09-25 |
| **HNSW Vector Search** | [Link](https://arxiv.org/abs/...) | `#ai` `#rag` `#paper` | Sub-5ms recall | 2026-09-25 |

Backup & Sync (.JSON)

Backup & Restore

BlockPi stores everything privately on your machine. To backup or transfer to another computer:

  • Click Export .JSON to download your full vault archive with exact IDs and timestamps.
  • On your new browser or profile, click Import .JSON.
  • BlockPi automatically deduplicates by URL so existing links are never duplicated or overwritten.
